Questions

1. Block accesses using nested loop join:

a) 5120
b) 10110
c) 10180
d) 11180

Answer: 10180

2. Hash join block accesses:

a) b1 + b2
b) 2(b1 + b2)
c) b1 + b2 + 2M
d) 2(b1 + b2 + M)

Answer: b1 + b2

3. Probe phase block accesses:

a) 31000
b) 20000
c) 11000
d) 21000

Answer: 11000

4. Sort-merge join properties:

a) m1 joins n1
b) m1 joins n2
c) m5 joins n5
d) Each m3 accessed once

Answer: m1 with n1, m1 with n2, and each m3 accessed once

5. Commutative & associative operators:

a) Intersection
b) Projection
c) Union
d) All

Answer: Only Intersection & Union

6. Optimized RA expression sizes (A, B):

a) 2,4
b) 4,4
c) 2,2
d) 4,2

Answer: 4,2

7. Durability is handled by:

a) Query processor
b) Application
c) Recovery module
d) Concurrency module

Answer: Recovery module of DBMS

8. Conflict pairs in schedule:

a) 2
b) 3
c) 4
d) 5

Answer: 3

9. Conflict serializable schedules:

a) S1 only
b) S2 only
c) Both
d) None

Answer: Both

10. No arcs in precedence graph means:

a) Serial
b) Not serializable
c) Conflict serializable
d) No conclusion

Answer: Conflict serializable (may be serial)
