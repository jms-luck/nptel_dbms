Q1

Consider two data files stored on a disk using 5060 and 60 blocks. We need to join these two files using the nested loop join method. The buffer size available is 52 blocks. The number of block accesses required by the method is (Ignore the block accesses required for writing the result):

  • 5120
  • 10110
  • 10180
  • 11180

Answer: 10180

Q2

Which of the following relational algebra operators are both commutative and associative? (i) INTERSECTION (ii) PROJECTION (iii) UNION

  • Only (i)
  • Only (i) and (iii)
  • Only (ii) and (iii)
  • All (i), (ii) and (iii)

Answer: Only (i) and (iii)

Q5

Q6

  • Only S1
  • Only S2

Q7

If the precedence graph of schedule has no arcs, then the schedule is a __________ schedule

  • serial
  • conflict serializable but not serial
  • conflict serializable and may be serial
  • No valid conclusion can be drawn

Answer: conflict serializable and may be serial
