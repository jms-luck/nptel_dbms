Questions

1. Functional dependency is a formal constraint among attributes.

a) True
b) False

Answer: True

2. Functional dependency depends on meaning of attributes.

a) True
b) False

Answer: True

3. FDs are used in schema design.

a) True
b) False

Answer: True

4. If B A then A B is trivial.

a) True
b) False

Answer: True

5. We use ______ to derive FDs.

a) Trivial FDs
b) Non-trivial FDs
c) Armstrong axioms
d) Keys

Answer: Armstrong axioms

6. FD statements S1 & S2:

a) Both True
b) Both False
c) S1 True
d) S2 True

Answer: Both True

7. FD implication:

a) EmpId EmpSalary
b) EmpName EmpSalary
c) EmpId, EmpName EmpSalary
d) Experience Salary

Answer: (EmpId, EmpName) EmpSalary

8. FD NOT holding in table:

a) EmpId EmpName
b) EmpMobileNum HomeCity
c) EmpId EmpAddress
d) (EmpName, HomeCity) EmpAddress

Answer: (EmpName, HomeCity) EmpAddress

9. Decomposition statements:

a) Both True
b) Both False
c) S1 True, S2 False
d) S1 False, S2 True

Answer: S1 True, S2 False

10. Closure result F contains:

a) A, H
b) A, H, F
c) A, H, F, B
d) A, H, F, B, C, D, G

Answer: A, H, F, B, C, D, G

11. Closure result variant:

a) A, H
b) A, H, F, B
c) A, H, F, B, C, D, G
d) A, H, F, B, E

Answer: A, H, F, B, E

12. Candidate key:

a) I
b) IE
c) E
d) IDE

Answer: IE

13. Armstrong axioms:

a) Both True
b) Both False
c) S1 True, S2 False
d) S1 False, S2 True

Answer: S1 True, S2 False
