Q1

The RDBMS stores data and meta-data separately.

  • True
  • False

Answer: True

Q2

The data type of an attribute is not part of meta-data.

  • True
  • False

Answer: False

Q3

A record can have a data element with an undefined type.

  • True
  • False

Answer: False

Q4

  • True
  • False

Answer: False

Q5

  • True
  • False

Answer: True

Q6

  • True
  • False

Answer: True

Q7

  • True
  • False

  • False

Answer: True

Q9

  • True
  • False

Answer: True

Q10

  • True
  • False

Answer: True

Q11

  • False

Q13

Q14

Q15

  • S1: True; S2: False

Q16

Consider the statements given below: S1: The Logical Data Independence allows us to modify the logical-level schema without affecting the view-level schema. S2: The Physical Data Independence allows us to modify the physical-level schema without affecting the logical-level schema. Choose the correct option:

  • S1: True; S2: True
  • S1: True; S2: False
  • S1: False; S2: True
  • S1: False; S2: False

Answer: S1: True; S2: True

Q17

Which abstraction level of the database system describes how the data is actually stored ?

  • Physical level
  • Logical level
  • View level
  • None of the above

Answer: Physical level

Q18

What is the most appropriate matching between the following sets: S1: {a: ER Model; b: Relational Model} S2: {p: Record-based model ; q: Conceptual level model; r: High-level data model; s: Representational level model}

  • a--p; b--q; a--r; b--s
  • a--p; b--q; a--s; b--r
  • a--q; b--p; a--r; b--s
  • a--q; b--p; a--s; b--r

Answer: a--q; b--p; a--r; b--s

Q19

Typically, a database administrator(DBA) is NOT responsible for:

  • Authorizing access to the database
  • Identifying database security breaches
  • Populating the records
  • To acquire required hardware and software resources

Answer: Populating the records
