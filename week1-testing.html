1. The RDBMS stores data and metadata separately.

a) True
b) False

Answer: True

2. The data type of an attribute is not part of metadata.

a) True
b) False

Answer: False

3. A record can have a data element with an undefined type.

a) True
b) False

Answer: False

4. An RDBMS cannot manage more than one database.

a) True
b) False

Answer: False

5. Schema is the description of the database.

a) True
b) False

Answer: True

6. One must define the logical schema of the database to design a database.

a) True
b) False

Answer: True

7. A database system does not hide storage details from users.

a) True
b) False

Answer: False

8. The view level abstraction hides the database logical schema.

a) True
b) False

Answer: True

9. RDBMS can provide concurrent access to users.

a) True
b) False

Answer: True

10. A log records all database update operations.

a) True
b) False

Answer: True

11. Recovery manager restores database after failure.

a) True
b) False

Answer: True

12. Recovery manager may fail to restore consistency.

a) True
b) False

Answer: False

13. Which are typical database applications?

a) Credit card system
b) Online reservation
c) Chat application
d) All

Answer: All of the above

14. Process that stores copies in multiple locations:

a) Paging
b) Query answering
c) Buffering
d) Replication

Answer: Replication

15. Conceptual vs Representational schema relation:

a) S1 True, S2 False
b) S1 True, S2 True
c) S1 False, S2 True
d) S1 False, S2 False

Answer: S1 False, S2 True

16. Data Independence:

a) Both True
b) S1 True only
c) S2 True only
d) Both False

Answer: Both True

17. Level describing actual storage:

a) Physical
b) Logical
c) View
d) None

Answer: Physical level

18. Match Models:

a) ap, bq, cr
b) aq, br, cp
c) aq, br, cp
d) aq, bp, cr

Answer: aq, br, cp

19. DBA is NOT responsible for:

a) Authorization
b) Security
c) Populating records
d) Resources

Answer: Populating the records
