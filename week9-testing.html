Questions

1. Unit of data transfer between disk and memory is block.

a) True
b) False

Answer: True

2. Blocking factor = ceil(B/r) for unspanned records.

a) True
b) False

Answer: False

3. Linked allocation scanning is faster than contiguous.

a) True
b) False

Answer: False

4. RDBMS supports fixed & variable length records.

a) True
b) False

Answer: True

5. Disk time calculation (seek + rotation):

a) 3 ms
b) 12 ms

Answer: 3 ms

6. Number of data buckets after hashing:
