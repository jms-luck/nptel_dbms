Questions

1. Statements on normalization:

S1: All normal forms use FDs
S2: Normalization reduces redundancy

a) Both True
b) S1 True
c) S2 True
d) S1 False, S2 True

Answer: S1 False, S2 True

2. Prime vs Non-prime attribute:

a) Candidate key
b) Super key
c) Primary key
d) Foreign key

Answer: Candidate key (for both blanks)

3. Closure C contains:

a) C, F
b) C, F, G, E
c) C, F, G, E, A
d) C, F, G, E, A, D

Answer: C, F, G, E, A, D

4. Incorrect candidate key:

a) AD
b) F
c) BC
d) CD

Answer: CD

5. Candidate key of relation R(part_no, supplier_id,...):

a) part_no
b) supplier_id
c) (supplier_id, part_no)
d) None

Answer: (supplier_id, part_no)

6. Highest normal form:

a) 1NF
b) 2NF
c) 3NF
d) BCNF

Answer: 1NF only

7. Statements on 2NF & 3NF:

a) Both True
b) S1 True
c) S2 True
d) S1 True, S2 False

Answer: S1 True, S2 False

8. Incorrect FD in minimal cover:

a) F D
b) DE F
c) FG CD
d) BC E

Answer: BC E

9. Normal form of relation:

a) 2NF
b) not in 2NF
c) 3NF
d) BCNF

Answer: not in 2NF
