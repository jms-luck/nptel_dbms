1. The RDBMS stores data and meta-data separately.

a) True
b) False

Answer: True

2. The data type of an attribute is not part of metadata.

a) True
b) False

Answer: False

3. A record can have a data element with an undefined type.

a) True
b) False

Answer: False

4. An RDBMS cannot manage more than one database.

a) True
b) False

Answer: False

5. Schema is the description of the database.

a) True
b) False

Answer: True

6. One must define the logical scheme of the database to design a database.

a) True
b) False

Answer: True

7. A database system does not hide "the process of storing and maintaining the data on disks" from the users.

a) True
b) False

Answer: False

8. The view level abstraction hides the database logical schema from the users.

a) True
b) False

Answer: True

9. RDBMS can provide concurrent access to its users.

a) True
b) False

Answer: True

10. A log is a record of all the database update operations.

a) True
b) False

Answer: True

11. The recovery manager is responsible for bringing the database back into a consistent state when a failure occurs.

a) True
b) False

Answer: True

12. Recovery-manager may sometimes fail to bring the database back into a consistent state.

a) True
b) False

Answer: False

13. Which of the following is(are) typical database application(s)?

a) Credit card system
b) Online reservation system
c) Chat application system
d) All of the above

Answer: All of the above

14. _ _ _ _ process stores copies of the database tables in several different locations simultaneously. Fill in the blank:

a) Paging
b) Query answering
c) Buffering
d) Replication

Answer: Replication

15. Consider the statements given below:
S1: Conceptual level schema is derived from the Representational-level schema.
S2: Representational-level schema is derived from the Conceptual level schema.
Choose the correct option:

a) S1: True; S2: False
b) S1: True; S2: True
c) S1: False; S2: True
d) S1: False; S2: False

Answer: S1: False; S2: True

16. Consider the statements given below:
S1: The Logical Data Independence allows us to modify the logical-level schema without affecting the view-level schema.
S2: The Physical Data Independence allows us to modify the physical-level schema without affecting the logical-level schema.
Choose the correct option:

a) S1: True; S2: True
b) S1: True; S2: False
c) S1: False; S2: True
d) S1: False; S2: False

Answer: S1: True; S2: True

17. Which abstraction level of the database system describes how the data is actually stored?

a) Physical level
b) Logical level
c) View level
d) None of the above

Answer: Physical level

18. What is the most appropriate matching between the following sets:
S1: {a: ER Model; b: Relational Model}
S2: {p: Record-based model; q: Conceptual level model; r: High-level data model; s: Representational level model}

a) a--p; b--q; a--r; b--s
b) a--p; b--q; a--s; b--r
c) a--q; b--p; a--r; b--s
d) a--q; b--p; a--s; b--r

Answer: a--q; b--p; a--r; b--s

19. Typically, a database administrator(DBA) is NOT responsible for:

a) Authorizing access to the database
b) Identifying database security breaches
c) Populating the records
d) To acquire required hardware and software resources

Answer: Populating the records
