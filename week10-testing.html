Questions

1. Order of B+ tree internal node is independent of:

a) Block size
b) Index field size
c) Block pointer size
d) Record pointer size

Answer: Record pointer size

2. After inserting key 5, valid leaf node is:

a) (4,5)
b) (6,6)
c) (6,7)
d) (4,6)

Answer: (5,6)

3. After deleting key 4, total nodes:

a) 8
b) 9
c) 10
d) 7

Answer: 10

4. Technique distributing data across disks with poor reliability:

a) Striping
b) Redundancy
c) Mirroring
d) Parity

Answer: Data striping

5. Matching RAID techniques:

a) Mirroring low reliability
b) Distributed parity high reliability
c) Dedicated parity uneven usage
d) All correct

Answer: a-2, b-3, c-4

6. Best index for query filtering:

a) sex
b) rollNo
c) deptId
d) None

Answer: rollNo

7. External sorting buffer increase:

S1: block accesses reduce
S2: runs reduce

a) Both True
b) Both False
c) S1 False, S2 True
d) S1 True, S2 False

Answer: S1 False, S2 True

8. Sorting runs:

a) First pass = 29 runs
b) Initial runs = 4
c) Second pass = 4
d) Merging reduced increases iterations

Answer: First pass = 29, Second pass = 4

9. Total block accesses in sorting:

a) 2280
b) 4096
c) 12288
d) 16384

Answer: 12288

10. Nested loop join statements:

S1: Each outer block read once
S2: Inner loop reads depend on buffer

a) Both True
b) Both False
c) S1 True
d) S2 True

Answer: Both True
