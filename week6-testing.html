Questions

1. Which SQL clauses can have aggregate functions?

a) GROUP BY
b) HAVING
c) SELECT
d) All

Answer: Only (b) and (c)

2. Views can never be used to update query.

a) True
b) False

Answer: False

3. Views do not maintain data integrity.

a) True
b) False

Answer: False

4. Views can be used in WHERE clause.

a) True
b) False

Answer: True

5. Aggregate operations can be used in views.

a) True
b) False

Answer: True

6. GROUP BY condition correctness:

a) Valid
b) Invalid

Answer: Valid

7. COUNT can be used in WHERE clause directly.

a) True
b) False

Answer: False

8. COUNT can be used in SELECT clause.

a) True
b) False

Answer: True

9. GROUP BY is required with HAVING always.

a) True
b) False

Answer: False

10. Correct HAVING query usage:

a) COUNT(*) in WHERE
b) COUNT(*) in HAVING
c) SUM in WHERE
d) None

Answer: COUNT(*) in HAVING

11. Maximum number of tuples in R S:

a) n + m
b) n m
c) n - m
d) n / m

Answer: n m

12. LIKE operator can be used with:

a) %
b) _
c) Both
d) None

Answer: Both

13. SQL query to find max salary professor:

a) Using ALL
b) Using MAX
c) Using subquery
d) All

Answer: Using subquery with ALL / MAX

14. Department with highest credits:

a) MIN
b) MAX
c) SUM
d) COUNT

Answer: SUM

15. Query using NOT EXISTS:

a) Correct
b) Incorrect

Answer: Correct

16. Programming approach vs DBMS:

a) DBMS better
b) Program better
c) Same
d) Depends

Answer: DBMS approach preferred
