1. A relation is a set of tuples.

a) True
b) False

Answer: True

2. Different tuples may have different number of components.

a) True
b) False

Answer: False

3. Each candidate key is a primary key.

a) True
b) False

Answer: False

4. Logical schema represents entity sets including relationships.

a) True
b) False

Answer: False

5. A relation always has a key.

a) True
b) False

Answer: True

6. A relation may have more than one key.

a) True
b) False

Answer: True

7. A relation can have at most one foreign key.

a) True
b) False

Answer: False

8. A foreign key is also a key for that relation.

a) True
b) False

Answer: False

9. Statements about attributes:

a) Both True
b) S1 True, S2 False
c) S1 False, S2 True
d) Both False

Answer: S1 False, S2 False

10. Maximum possible keys in relation:

a) 1
b) 4
c) 8
d) 16

Answer: 16

11. Statements about keys:

a) All True
b) Only S1 True
c) Only S2 True
d) Only S3 True

Answer: S1 False, S2 True, S3 False

12. Number of tuples after relational algebra operation:

a) 0
b) 1
c) 2
d) 3

Answer: 1

13. Query result using relational algebra:

a) Option 1
b) Option 2
c) Option 3
d) Option 4

Answer: Correct query is based on join then projection

14. Maximum attributes in R1 R2:

a) m + n
b) m * n
c) m - n
d) m / n

Answer: m + n

15. Result of projection A,B,C(D):

a) Option 1
b) Option 2
c) Option 3
d) Option 4

Answer: Reduced attribute set

16. For R1, R2 to be union-compatible, attribute names must match.

a) True
b) False

Answer: False

17. For R1, R2 to be union-compatible, same number of attributes required.

a) True
b) False

Answer: True

18. Domains of corresponding attributes must match.

a) True
b) False

Answer: True

19. Division operator requires same attributes.

a) True
b) False

Answer: False
