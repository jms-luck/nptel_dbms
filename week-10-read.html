Which of the following statements are true regarding the merge phase

  • The number of runs in the result of the first iteration of the merge phase is 29
  • The total number of iterations in the merge phase is 4
  • The number of runs in the result of the second iteration of the merge phase is 4
  • If the degree of merging is reduced, the number of iterations in the merge phase increases

Answer: The number of runs in the result of the first iteration of the merge phase is 29, The number of runs in the result of the second iteration of the merge phase is 4, If the degree of merging is reduced, the number of iterations in the merge phase increases
