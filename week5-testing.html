Academic Institution Relational Database Schema

Use the following schema in the questions wherever required:

student( rollNo, name, degree, year, sex, deptNo, advisor )
department( deptId, name, hod, phone )
professor( empId, name, sex, startYear, deptNo, phone )
course( courseId, cname, credits, deptNo )
enrollment( rollNo, courseId, sem, year, grade )
teaching( empId, courseId, sem, year, classRoom )
preRequisite( preCourseId, courseId )

Foreign Key Constraints

  • deptNo is a foreign key in student, professor, and course referring to deptId of department.
  • advisor is a foreign key in student referring to empId of professor.
  • hod is a foreign key in department referring to empId of professor.
  • rollNo is a foreign key in enrollment referring to rollNo of student.
  • courseId is a foreign key in enrollment and teaching referring to courseId of course.
  • empId is a foreign key in teaching referring to empId of professor.
  • preCourseId and courseId are foreign keys in preRequisite referring to courseId of course.

1. Which of the following is NOT a DDL command?

a) create
b) insert
c) alter
d) drop

Answer: insert

2. What is the relation between NOT NULL and DEFAULT?

a) NOT NULL depends on DEFAULT
b) NOT NULL must be specified if DEFAULT used
c) DEFAULT must be specified if NOT NULL used
d) Both independent

Answer: Both can be specified independently

3. Which key constraint can be specified only once?

a) Primary key
b) Foreign key
c) Unique key
d) All

Answer: All (in this context considered once per attribute set)

4. Negation of ALL operator in SQL:

a) NOT ALL
b) NOT ANY
c) ANY
d) NOT EXISTS

Answer: ANY

5. Query correction (credits condition):

a) c1.courseId = c2.courseId
b) c1.courseId <> c2.courseId
c) c1.credits = c2.credits
d) c1.credits <> c2.credits

Answer: c2.credits < c1.credits

6. Courses with at least two prerequisites:

a) Query 1
b) Query 2
c) Query 3
d) Query 4

Answer: Query using EXISTS twice with different prerequisites

7. Students with S grade in all courses:

a) Query 1
b) Query 2
c) Query 3
d) Query 4

Answer: NOT EXISTS with nested NOT EXISTS

8. Self join result condition (p1.staffNo = p2.staffNo):

a) Includes all pairs
b) Excludes same experience
c) Includes same experience pairs
d) Only distinct pairs

Answer: Includes all pairs with same number of years of experience

9. Number of tuples when staffNo is unique:

a) 10
b) 50
c) 90
d) 100

Answer: 10
